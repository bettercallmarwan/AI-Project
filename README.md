# Knapsack Solver with Genetic Algorithm (GUI)

This is a Python GUI application that solves the **Knapsack Problem** using a **Genetic Algorithm**. It supports both **0/1 Knapsack** and **Unbounded Knapsack**.

##  Features

- Solve 0/1 and Unbounded Knapsack problems
- Easy-to-use graphical interface (Tkinter)
- Customize number of items, their weights and values
- Set max weight and number of generations
- Real-time output per generation
- Fitness progress graph using matplotlib

##  Requirements

- Python 3.x
- `matplotlib`
